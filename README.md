# e-plantShopping

## Paradise Nursery Shopping Application

**Repository:** e-plantShopping

Paradise Nursery is a React-based online plant shopping application. The application allows users to browse different types of plants, view plant information, add plants to a shopping cart, and manage the quantities of items in the cart.

## Features

* Landing page for Paradise Nursery
* Navigation between the home, plants, and cart sections
* Plant categories
* Plant cards with images, names, descriptions, and prices
* Add plants to the shopping cart
* Increase or decrease item quantities
* Remove items from the cart
* Calculate the cart total
* Responsive user interface

## Technologies

* React
* JavaScript
* Vite
* HTML
* CSS
